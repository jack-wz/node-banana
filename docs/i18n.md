# 中英文国际化（i18n）模块设计

> 目标：全应用支持 English / 中文切换，覆盖画布壳层、节点 UI、所有弹窗、
> 设置页面、引导流程（FTUX/Quickstart/教程）。

## 架构

```
src/i18n/
  types.ts   — Locale ("en" | "zh")、Dictionary（扁平点分键）
  en.ts      — 英文字典（默认 + 回退源，~380 键）
  zh.ts      — 中文字典（缺键自动回退英文）
  store.ts   — zustand locale store + translate() + 非 hook t()
  index.ts   — useT() / useNodeTypeLabel() / nodeCategoryKey()
```

## 关键决策

1. **默认英文**：既有行为与全部测试断言保持不变（基线 0 新增）。
2. **扁平点分键**：`header.saveProject`、`nodeType.nanoBanana`、
   `setup.panMode` 等按界面区域命名；无嵌套对象，查找/去重简单。
3. **回退链**：zh 缺键 → en → 原始键名。`translate(locale, key, params)`
   支持 `{param}` 插值（split/join 实现，同名参数多处替换）。
4. **持久化**：`localStorage["node-banana-locale"]`；
   SSR 安全——store 恒以 `"en"` 初始化，page.tsx 挂载后 `initLocale()`
   水合持久值，避免 hydration mismatch。
5. **两个入口**：组件内 `const t = useT()`（订阅 locale 自动重渲染）；
   组件外（store/工具函数）`import { t } from "@/i18n"`（读当前值）。
6. **复数/单复数**：中文无复数，英文需要处拆双键
   （如 `cost.nodeCountOne/Many`、`history.countTitleOne/Many`）。
7. **节点类型名集中**：`nodeType.<type>` 一键供给 Library/Tab 选择器/
   右键菜单/FAB/连线放置菜单；分类名 `nodeCategory.<name>` 同理。
   Tab 选择器搜索同时匹配中英文（fuzzyMatch 双语）。

## 切换入口

- Header 右 pill：EN/中 紧凑切换按钮（`LanguageSwitcher`）
- 项目设置 → 画布页签：语言选择段（与平移/缩放/选择模式并列）

| 区域 | 组件 |

| 顶栏/壳层 | Header、IconRail、CanvasToolbars、FloatingActionBar、TasksPanel、LanguageSwitcher |
| 面板 | LibraryPanel、NodeSettingsPanel、NodePickerMenu、CanvasContextMenu、ConnectionDropMenu |
| 弹窗 | ProjectSetupModal（4 页签全量+语言选择）、KeyboardShortcutsDialog、CostDialog、AnnotationModal、SplitGridSettingsModal、ModelSearchDialog、WelcomeModal 各视图 |
| 引导 | FTUXModal + 4 步骤、Quickstart 全部视图、ftuxStore 19 条教程消息 |
| 节点 | FloatingNodeHeader、Prompt/Generate/Image/Video/Audio 输入输出、LLM、StickyNote 等高频 UI |
| 反馈 | Toast、MultiSelectToolbar、EdgeToolbar、CostIndicator、GlobalImageHistory |
